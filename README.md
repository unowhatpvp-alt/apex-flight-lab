# APEX / 飞车实验室

可在电脑和手机浏览器运行的独立 3D 飞车特技游戏。接手原仓库的初始化 README，补全游戏、赛道、输入、损伤报告和部署内容。

[在线试玩](https://unowhatpvp-alt.github.io/apex-flight-lab/)

## 操作

| 按键 | 功能 |
| --- | --- |
| W / ↑ | 加速 |
| S / ↓ | 刹车 |
| ← / → 或 Q / E | 横向转向 |
| A / D | 空中左侧滚 / 右侧滚（绕车身纵轴） |
| 空格 | 按住底部喷气，推力沿车身局部朝上方向 |
| M | 开关吸附辅助，适用于回环和倒挂路段 |
| C | 切换车后跟随 / 远距跟随 / 贴近跟随 |
| R | 重新开始 |
| Esc / P | 暂停或继续 |

手机支持多指同时按住按钮，横屏视野更宽。落地后自动补充喷气储量。初次建议先加速，短喷 0.5～1 秒，轻点 A/D 调平左右倾斜。前后俯仰由坡道、离地惯性和空气阻尼自动决定；高难度断桥前需要减速控制落点。

## 内容

- 赤砂试验场、天际回环、逆重力走廊、月面远征、极限零界五条赛道。
- 完整三维姿态、重力、随车身旋转的局部推力、空中侧滚、落地撞击和倒挂吸附。
- 封闭路面和车辆网格；碰撞覆盖车头、侧面、车顶、桥底、断桥端面、护栏和地面。空间回环错开自身相交的位置。
- 镜头从车后跟随方向和位置，侧滚时保持独立参照，并在靠近障碍物时缩短距离。
- 车身、悬挂、电池和推进器四项损伤，以及车辆可视变形/冒烟。
- 通关或失败后显示评分、评级、滞空时间、翻转次数、最高速度与损伤报告。
- 本机最高分保存在浏览器 localStorage；没有账号或后端。
- Three.js WebGL 2 硬件加速渲染，流畅 / 均衡 / 高画质 / 极致四档及自动选择，记住本机偏好。
- 高画质增加精细车身、粗糙度和凹凸纹理、环境反射、环境遮蔽及柔和光晕；极致增加网格精度和 4096 像素阴影贴图。
- 主动开启的合成音效。

## 本地运行与测试

需要 Python 3 提供静态 HTTP 服务；运行时依赖已经放在 vendor 中，无需联网安装。

```sh
python -m http.server 8744 --bind 127.0.0.1
```

打开 http://127.0.0.1:8744 。不能用 file:// 直接打开 ES module。

物理测试需要 Node.js：

```sh
node physics.test.mjs
node camera.test.mjs
```

测试覆盖五条赛道可控通关、侧滚轴向与俯仰独立、坡道俯仰惯性、旋转后推力、侧滚计分、车身包围体接触、桥底/断桥端面/地面碰撞、倒挂吸附、护栏、重置、时间限制及 30/120 FPS 一致性。镜头测试覆盖跟随朝向、独立侧滚参照、障碍物避让及完整空间回环。

## 部署

GitHub Pages 发布 main 分支根目录即可。全部资源使用相对路径，Three.js 随项目托管，无外部字体/CDN运行依赖。`.nojekyll` 关闭 Jekyll。

## 实现范围

这是一款以飞行跑车为灵感的街机模拟游戏，与 Tesla / SpaceX 没有隶属关系。赛道接地采用轨迹约束，飞行使用固定 120 Hz 积分的重力与推力模型；不是工程级整车刚体、多轮悬挂或软体碰撞模拟。吸附辅助、燃料补充、月面重力和损伤数值为可玩性设计，不代表真实车辆参数。

车辆和环境为程序生成的实时 3D 网格；没有使用 Blender 或离线光线追踪。自动画质根据屏幕和输入设备选择，不能代表某张显卡的性能保证。实体手机、多指触控与不同 GPU 的实际表现需在目标设备上确认。
