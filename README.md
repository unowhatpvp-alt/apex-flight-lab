# APEX / 飞车实验室

可在电脑与手机浏览器玩的独立 3D 飞车特技模拟游戏。选择车辆和试验场，驾驶、喷气、空中侧滚，并在结束后查看分数与车辆损伤。

[在线试玩](https://unowhatpvp-alt.github.io/apex-flight-lab/) · [English documentation](README.en.md)

版本：**1.2.0**。游戏内可随时通过右上角 **EN / 中文** 切换语言。

## 驾驶操作

| 按键 | 功能 |
| --- | --- |
| W / ↑ | 加速 |
| S / ↓ | 刹车 |
| A / D 或 ← / → | 左右转向 |
| Q / E | 空中向左 / 向右侧滚，绕车身纵轴旋转 |
| 空格 | 按住底部喷气，推力沿车身局部朝上方向 |
| M | 开关吸附辅助，适用于回环和倒挂路段 |
| C | 切换车后、远距、贴近跟随视角 |
| T | 返回最近的安全路面，保留本局时间、损伤与喷气储量 |
| R | 重新开始一局 |
| Esc / P | 暂停或继续 |

手机配有对应的触控按钮，支持同时按住多个按钮。横屏有更宽的驾驶视野。初次建议先加速，短喷 0.5～1 秒，再轻点 Q / E 调平侧倾，使四轮朝向落地路面。喷气储量会在回到赛道后补充。

驶出赛道后可以在场地内继续自由驾驶与飞行，没有 180 秒自动结束限制。**正常完赛需要实际穿过终点门**：从门外绕过、从门上方飞过或反向经过都不会直接完成。错过终点后可以继续探索，或按 T 返回安全路面再尝试。严重碰撞或车辆严重损坏仍会导致失败结算。

## 六个试验场

| 试验场 | 主要内容 |
| --- | --- |
| 悬空发布场 / The Reveal（默认） | 悬空断续跑道与两段长 22 / 24 米的橙色平台；接近后倒计时消失，画面和碰撞同步移除 |
| 赤砂试验场 | 宽直道、起伏路面与入门飞跃 |
| 天际回环 | 完整空间回环与断桥 |
| 逆重力走廊 | 高架倒挂行驶、桥底与波浪路面 |
| 月面远征 | 为游戏调校的低重力与长距离腾空 |
| 极限零界 | 连续断桥、回环和倒挂组合 |

回环与倒挂桥采用空间错层，避免道路自身重叠。赛道有检查点、进度条、小地图及消失平台倒计时提示。

## 四款车辆

| 车辆 | 驾驶取向 |
| --- | --- |
| 赤焰 Roadster / APEX ROADSTER | 轻快响应，适合空中特技 |
| 蔚蓝 GT / VOLT GT | 较重车身，稳定巡航与均衡操控 |
| 荒野 Rally / TERRA RALLY | 较软悬挂，对落地撞击更宽容 |
| 银翼 Prototype / SILVER PROTOTYPE | 低车身、高抓地力与高速性能 |

四款车具有不同外形、质量、加速度、最高速度、转向响应、抓地力、悬挂和损伤调校。数值均属于虚构试验车设定，不代表实际量产车参数。

转向包含车轮转角、车身偏航、速度相关的转向幅度和轮胎侧滑。飞行使用完整三维姿态，喷气方向随车身旋转；底部白色冷凝喷流与侧向姿态喷口提供操作反馈。车身、悬挂、电池、推进器分别记录损伤，并以可视变形与烟雾表现。

结算显示分数、评级、驾驶时间、侧滚次数、滞空时间、最高速度和损伤报告。最高分、语言与画质等偏好保存在当前浏览器中，无需账号或后端。

## 图形与 Blender 资产

游戏实时画面采用 **Three.js / WebGL 2 / PBR 材质**，使用浏览器 GPU 加速。提供自动、流畅、均衡、高画质和极致档位；高档位增加细节、阴影、环境遮蔽与柔和光晕，极致档位使用 4096 像素阴影贴图。**运动模糊为可选项，默认关闭**；启用后根据相机运动与车速增强。

车辆和赛道是程序生成的实时网格。车漆反射使用真正由 **Blender 5.2.2 Cycles、RTX 5080、OptiX、96 采样**离线烘焙的原创摄影棚 HDR 环境：白色柔光箱、暗色中性墙面、少量青色光与地面反弹光。

- 网页资产：`assets/studio-env.js`，256 × 128、线性 RGBA 半浮点，约 350 KB，保留高于 1 的 HDR 亮度。
- 本地交付额外包含 `../blender-source/apex-studio-environment.blend` 和 `../studio-environment-preview.png`。这些文件位于网站根目录之外，不随 GitHub Pages 部署。
- Blender 负责离线资产烘焙；浏览器内的游戏采用实时光栅化渲染，不运行 Cycles 或路径追踪。

制作过程只修改本项目文件；没有修改系统、驱动设置或 Valorant 文件。Blender 通过 `--background --factory-startup` 启动，在当前进程内选择 GPU，未保存用户偏好设置。游戏运行不要求安装 Blender。

## 本地运行

所有运行时资源随项目托管，不依赖外部字体、CDN 或联网安装。使用 Python 3 在此目录启动静态服务：

```sh
python -m http.server 8744 --bind 127.0.0.1
```

浏览器打开 [本地试玩地址](http://127.0.0.1:8744/)。由于使用 ES modules，请通过 HTTP 服务访问，不要直接双击 `index.html`。

## 验证

物理与镜头检查使用 Node.js：

```sh
node physics.test.mjs
node camera.test.mjs
```

物理检查覆盖四款车与六条赛道的 24 种组合、侧滚轴向、三维推力、坡道俯仰、速度相关转向、轮胎侧滑、车身接触、桥底与断桥端面、倒挂吸附、护栏、消失平台碰撞移除、自由探索、保留状态的返回赛道、真实终点门穿越，以及 30 / 120 FPS 一致性。镜头检查覆盖跟随朝向、独立侧滚参照、障碍物避让与完整空间回环。

浏览器视口检查包含 **390 × 844 英文竖屏菜单**及横屏布局；开始按钮在该竖屏视口内可达。以上属于浏览器视口与交互验证，并不等同于在实体手机上测试多指触控、温度或 GPU 性能。

## 模拟范围与许可

这是独立街机驾驶模拟游戏，与 Tesla / SpaceX 无隶属关系。物理采用固定 120 Hz 积分、自定义赛道接触、车身包围体、轮胎抓地与飞行动力模型；它不是工程级多刚体、多轮悬挂、轮胎热力学或软体碰撞仿真。主动吸附、自动补气、低重力和损伤数值服务于游戏可玩性。
